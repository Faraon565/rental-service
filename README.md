# Rental Service

Учебный backend-сервис для аренды жилья, разработанный на Go.

В проекте реализованы регистрация и авторизация пользователей, создание объектов жилья, оформление бронирований и асинхронная обработка заявок. Для локального запуска всех компонентов используется Docker Compose.

## Основные возможности

- регистрация и авторизация пользователей
- хранение паролей в виде bcrypt-хешей
- JWT-авторизация
- работа с PostgreSQL
- создание объектов жилья
- создание и просмотр бронирований
- асинхронная обработка бронирований через RabbitMQ
- отдельный worker для обработки очереди
- сбор HTTP-метрик
- мониторинг через Prometheus и Grafana
- генерация нагрузки с помощью отдельного loadgen-сервиса
- простой веб-интерфейс для работы с сервисом
- graceful shutdown HTTP-сервера

## Архитектура

Backend разделён на несколько основных слоёв:

- `delivery` отвечает за HTTP-обработчики и middleware
- `usecase` содержит основную бизнес-логику
- `repository` отвечает за работу с PostgreSQL
- `rabbitmq` содержит взаимодействие с очередью сообщений

Для обработки бронирований используется отдельный worker. После создания бронирования приложение отправляет событие в RabbitMQ, после чего worker получает его и обновляет состояние заявки.

## Запуск проекта

Для запуска необходимы Docker и Docker Compose.

```bash
docker compose up --build
```

После запуска будут доступны:

| Сервис | Адрес |
| --- | --- |
| API | http://localhost:8080 |
| Веб-интерфейс | http://localhost:8080/ui |
| Метрики | http://localhost:8080/metrics |
| RabbitMQ Management | http://localhost:15672 |
| Prometheus | http://localhost:9090 |
| Grafana | http://localhost:3000 |

Остановить сервисы:

```bash
docker compose down
```

Удалить сервисы вместе с созданными volumes:

```bash
docker compose down -v
```

## API

### Регистрация

```http
POST /auth/register
```

Пример тела запроса:

```json
{
  "email": "user@example.com",
  "password": "password",
  "full_name": "Test User"
}
```

### Авторизация

```http
POST /auth/login
```

```json
{
  "email": "user@example.com",
  "password": "password"
}
```

В ответ возвращается JWT-токен.

### Создание бронирования

```http
POST /bookings/create
```

Для запроса требуется JWT-токен.

```json
{
  "property_id": 1,
  "date_from": "2026-10-25",
  "date_to": "2026-10-30"
}
```

### Получение бронирований пользователя

```http
GET /bookings/list
```

Для запроса также требуется JWT-токен.

## Асинхронная обработка

После создания бронирования приложение публикует событие в очередь RabbitMQ.

Отдельный worker получает событие и обрабатывает заявку. Таким образом, HTTP-сервис не выполняет всю обработку непосредственно во время пользовательского запроса.

## Мониторинг

Приложение предоставляет endpoint:

```text
/metrics
```

Prometheus собирает метрики приложения, после чего они могут отображаться на настроенном дашборде Grafana.

В проект также входит `loadgen`, который создаёт тестовую нагрузку и позволяет наблюдать изменение метрик во время работы сервиса.

## Веб-интерфейс

Для демонстрации основных возможностей реализован простой интерфейс:

```text
http://localhost:8080/ui
```

Через него можно зарегистрироваться, войти в аккаунт, добавить объект жилья, создать бронирование и посмотреть его состояние.
